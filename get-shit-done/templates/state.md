# State Template

Template for `.planning/STATE.md` — project memory.

```markdown
# Project State

## Current Position
**Status:** [Ready to start / In progress / Complete]
**Next:** [Next feature name or "Done"]

## Decisions
- [date]: [Decision made and why]

## Notes
- [Anything to remember]
```

## Purpose

STATE.md is the project's memory across sessions.

- Read at start of every session
- Updated after every significant action
- Keeps decisions and notes from getting lost

## Guidelines

- Keep it short (under 50 lines)
- Only track what matters
- Decisions should have rationale
- Notes are temporary (clean up when addressed)
